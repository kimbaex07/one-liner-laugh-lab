A one-line excuse from a robot vacuum caught red-handed after eating a sock. The vacuum denies everything and claims the sock applied for asylum inside its dustbin, so under international vacuum law it had no choice but to take it in. One sentence, one joke, no wasted words — a household mishap reframed as a mock-legal refugee case, with the punchline landing on the very last words.

## Run it

```sh
python3 main.py
```
